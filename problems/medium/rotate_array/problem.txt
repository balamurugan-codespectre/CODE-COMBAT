# Rotate Array (Medium - 200 Points)

## Description
Given an integer array `nums` of size `N`, rotate the array to the right by `K` steps, where `K` is non-negative.

## Input Format
The first line contains two integers `N` and `K`.
The second line contains `N` integers.

## Output Format
Print the rotated array elements separated by spaces.

## Constraints
1 <= N <= 10^5
0 <= K <= 10^9
-10^9 <= nums[i] <= 10^9

## Examples

### Example 1
Input:
```
7 3
1 2 3 4 5 6 7
```
Output:
```
5 6 7 1 2 3 4
```
Explanation: Rotate 1 step: [7,1,2,3,4,5,6]
Rotate 2 steps: [6,7,1,2,3,4,5]
Rotate 3 steps: [5,6,7,1,2,3,4]

### Example 2
Input:
```
4 2
-1 -100 3 99
```
Output:
```
3 99 -1 -100
```
Explanation: Rotated right by 2 steps.
