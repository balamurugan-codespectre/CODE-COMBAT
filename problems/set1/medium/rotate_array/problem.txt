# Rotate Array [Medium - 200 pts]

## Category
Arrays

## Description
Given an array `nums`, rotate the array to the right by `k` steps, where `k` is non-negative.

## Input Format
The first line contains `N` and `K`.
The second line contains `N` space-separated integers.

## Output Format
Print the rotated array space-separated.

## Constraints
1 <= N <= 10^5
0 <= K <= 10^5
-10^9 <= nums[i] <= 10^9

## Examples (Visible 2 of 5)

### Example 1
Input:
```
7 3
1 2 3 4 5 6 7
```
Output:
```
5 6 7 1 2 3 4
```
Explanation: Rotate 3 steps right.

### Example 2
Input:
```
4 2
-1 -100 3 99
```
Output:
```
3 99 -1 -100
```
Explanation: Rotate 2 steps right.
