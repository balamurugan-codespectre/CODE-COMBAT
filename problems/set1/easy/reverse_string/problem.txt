# Reverse String [Easy - 100 pts]

## Category
Strings

## Description
Given a single line string `S`, print the reverse of the string.

All characters including letters, digits, and symbols should be inverted in place.

## Input Format
A single line containing the string `S`.

## Output Format
Print the reversed string.

## Constraints
1 <= length(S) <= 10^5

## Examples (Visible 2 of 5)

### Example 1
Input:
```
hello
```
Output:
```
olleh
```
Explanation: Reversing 'hello' gives 'olleh'.

### Example 2
Input:
```
CodeCombat 2026
```
Output:
```
6202 tabmoCedoC
```
Explanation: Spaces and numbers are preserved in reverse.
