# Shortest Path in Unweighted Graph [Hard - 300 pts]

## Category
BFS

## Description
Given an unweighted undirected graph with `V` vertices and `E` edges, find the length of the shortest path from vertex `S` to vertex `D`.

If no path exists, print `-1`.

## Input Format
The first line contains `V`, `E`, `S`, `D`.
The next `E` lines each contain `u` and `v` denoting an edge.

## Output Format
Print the minimum number of edges from `S` to `D`.

## Constraints
1 <= V <= 10^5
0 <= E <= 2 * 10^5

## Examples (Visible 2 of 5)

### Example 1
Input:
```
4 4 0 3
0 1
1 2
2 3
0 2
```
Output:
```
2
```
Explanation: Shortest path: 0 -> 2 -> 3 has length 2.

### Example 2
Input:
```
3 1 0 2
0 1
```
Output:
```
-1
```
Explanation: Vertex 2 is not connected to 0.
