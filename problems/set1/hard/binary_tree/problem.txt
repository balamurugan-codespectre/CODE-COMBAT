# Binary Tree Level Order Traversal [Hard - 300 pts]

## Category
Trees & BFS

## Description
Given a serialized binary tree in level-order format where `-1` denotes `null`, print the level-order traversal level by level.

Print each level on a new line with space-separated values.

## Input Format
The first line contains `N`, the number of elements in the serialized array.
The second line contains `N` space-separated integers representing nodes in level order.

## Output Format
Print each level's node values on a separate line.

## Constraints
0 <= N <= 10^5
Node values between -1000 and 1000.

## Examples (Visible 2 of 5)

### Example 1
Input:
```
7
3 9 20 -1 -1 15 7
```
Output:
```
3
9 20
15 7
```
Explanation: Level 1: 3 | Level 2: 9, 20 | Level 3: 15, 7.

### Example 2
Input:
```
1
1
```
Output:
```
1
```
Explanation: Tree with a single root node.
