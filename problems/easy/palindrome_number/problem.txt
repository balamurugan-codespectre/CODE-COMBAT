# Palindrome Number (Easy - 100 Points)

## Description
Given an integer `X`, return `true` if `X` is a palindrome integer, or `false` otherwise.

An integer is a palindrome when it reads the same backward as forward. Negative numbers are not palindromes.

## Input Format
A single line containing the integer `X`.

## Output Format
Print `true` or `false` (lowercase).

## Constraints
-2^31 <= X <= 2^31 - 1

## Examples

### Example 1
Input:
```
121
```
Output:
```
true
```
Explanation: 121 reads 121 from left to right and right to left.

### Example 2
Input:
```
-121
```
Output:
```
false
```
Explanation: From left to right it reads -121. From right to left it is 121-.
