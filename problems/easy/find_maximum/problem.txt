# Find Maximum Element [Easy - 100 pts]

## Category
Arrays

## Description
Given an array of `N` integers, find and print the maximum value present in the array.

## Input Format
The first line contains an integer `N`.
The second line contains `N` space-separated integers.

## Output Format
Print the maximum integer value.

## Constraints
1 <= N <= 10^5
-10^9 <= arr[i] <= 10^9

## Examples (Visible 2 of 5)

### Example 1
Input:
```
5
1 4 2 8 5
```
Output:
```
8
```
Explanation: The maximum element is 8.

### Example 2
Input:
```
3
-10 -5 -20
```
Output:
```
-5
```
Explanation: The maximum among negative numbers is -5.
