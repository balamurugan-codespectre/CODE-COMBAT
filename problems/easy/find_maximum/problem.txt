# Find Maximum (Easy - 100 Points)

## Description
Given an array of `N` integers, find and print the maximum value contained in the array.

## Input Format
First line contains `N`.
Second line contains `N` integers.

## Output Format
Print the maximum integer in the array.

## Constraints
1 <= N <= 10^5
-10^9 <= array elements <= 10^9

## Examples

### Example 1
Input:
```
5
1 9 3 7 4
```
Output:
```
9
```
Explanation: The maximum element is 9.

### Example 2
Input:
```
3
-10 -50 -5
```
Output:
```
-5
```
Explanation: The maximum element among negatives is -5.
