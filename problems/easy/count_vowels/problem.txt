# Count Vowels (Easy - 100 Points)

## Description
Given a string `S`, count and print the total number of vowels (`a, e, i, o, u`, case-insensitive) present in the string.

## Input Format
A single line containing the string `S`.

## Output Format
Print the total count of vowels.

## Constraints
1 <= length(S) <= 10^5

## Examples

### Example 1
Input:
```
CodeCombat
```
Output:
```
4
```
Explanation: Vowels are 'o', 'e', 'o', 'a' -> 4.

### Example 2
Input:
```
xyz
```
Output:
```
0
```
Explanation: No vowels in 'xyz'.
