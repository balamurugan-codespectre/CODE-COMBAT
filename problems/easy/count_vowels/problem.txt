# Count Vowels [Easy - 100 pts]

## Category
Strings

## Description
Given a single line string `S`, count and print the total number of vowels (`a`, `e`, `i`, `o`, `u`, both lowercase and uppercase).

## Input Format
A single line containing the string `S`.

## Output Format
Print the total count of vowels.

## Constraints
1 <= length(S) <= 10^5

## Examples (Visible 2 of 5)

### Example 1
Input:
```
Hello World
```
Output:
```
3
```
Explanation: Vowels are 'e', 'o', 'o'.

### Example 2
Input:
```
AEIOU aeiou
```
Output:
```
10
```
Explanation: 5 uppercase and 5 lowercase vowels.
