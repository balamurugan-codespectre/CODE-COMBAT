# Dijkstra's Shortest Path (Hard - 300 Points)

## Description
Given a directed weighted graph with `V` vertices (numbered `0` to `V-1`) and `E` edges with non-negative weights, find the shortest distance from a starting vertex `S` to all other vertices.

Print the distances for vertices `0, 1, ..., V-1` separated by a space. If a vertex is unreachable, print `-1` for that vertex.

## Input Format
First line contains `V` and `E`.
Next `E` lines each contain `u v w` representing a directed edge from `u` to `v` with weight `w`.
Last line contains source vertex `S`.

## Output Format
Print `V` space-separated integers representing shortest distances.

## Constraints
1 <= V <= 10^4
0 <= E <= 5*10^4
0 <= u, v, S < V
0 <= w <= 10^6

## Examples

### Example 1
Input:
```
5 6
0 1 4
0 2 2
1 2 1
1 3 5
2 3 8
3 4 3
0
```
Output:
```
0 4 2 9 12
```
Explanation: Distances from 0: 0->0=0, 0->1=4, 0->2=2, 0->1->3=9, 0->1->3->4=12.
