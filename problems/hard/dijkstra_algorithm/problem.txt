# Dijkstra's Shortest Path [Hard - 300 pts]

## Category
Graphs

## Description
Given a weighted directed graph with `V` vertices (0 to V-1) and `E` edges, compute the shortest path distance from a source vertex `S` to all vertices.

If a vertex is unreachable, print `-1` for its distance.

## Input Format
The first line contains `V`, `E`, and `S`.
The next `E` lines each contain `u`, `v`, and `w` denoting a directed edge from `u` to `v` with weight `w`.

## Output Format
Print `V` space-separated integers representing shortest distances from `S` to vertices 0 through V-1.

## Constraints
1 <= V <= 10^4
0 <= E <= 10^5
0 <= w <= 10^5

## Examples (Visible 2 of 5)

### Example 1
Input:
```
4 4 0
0 1 1
0 2 4
1 2 2
2 3 1
```
Output:
```
0 1 3 4
```
Explanation: Distances from 0: 0->0=0, 0->1=1, 0->1->2=3, 0->1->2->3=4.

### Example 2
Input:
```
3 2 0
0 1 5
1 2 10
```
Output:
```
0 5 15
```
Explanation: Linear path from 0 to 2.
