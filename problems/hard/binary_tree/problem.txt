# Binary Tree Level Order Traversal (Hard - 300 Points)

## Description
Given the level-order array representation of a binary tree (where `-1` denotes a `null` node), print the level-order traversal of its node values line by line from top to bottom.

## Input Format
A single line containing integers separated by space representing the binary tree in level order.

## Output Format
Print each level's values on a separate line separated by space.

## Constraints
1 <= number of nodes <= 10^4
-10^4 <= node value <= 10^4

## Examples

### Example 1
Input:
```
3 9 20 -1 -1 15 7
```
Output:
```
3
9 20
15 7
```
Explanation: Level 0: [3], Level 1: [9, 20], Level 2: [15, 7].
