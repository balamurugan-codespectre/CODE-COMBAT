# N-Queens Solutions Count [Hard - 300 pts]

## Category
Backtracking

## Description
The `N-queens` puzzle is the problem of placing `N` queens on an `N x N` chessboard such that no two queens attack each other.

Given an integer `N`, return the total number of distinct solutions.

## Input Format
A single line containing the integer `N`.

## Output Format
Print the number of distinct valid board configurations.

## Constraints
1 <= N <= 12

## Examples (Visible 2 of 5)

### Example 1
Input:
```
4
```
Output:
```
2
```
Explanation: There are two distinct solutions to the 4-queens puzzle.

### Example 2
Input:
```
1
```
Output:
```
1
```
Explanation: A 1x1 board has exactly 1 queen.
