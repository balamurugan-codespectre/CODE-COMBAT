# N-Queens Solutions Count (Hard - 300 Points)

## Description
The `N`-queens puzzle is the problem of placing `N` chess queens on an `N×N` chessboard so that no two queens attack each other.

Given an integer `N`, print the total number of distinct solutions.

## Input Format
A single line containing the integer `N`.

## Output Format
Print the number of distinct valid solutions.

## Constraints
1 <= N <= 12

## Examples

### Example 1
Input:
```
4
```
Output:
```
2
```
Explanation: There are two distinct solutions to the 4-queens puzzle.

### Example 2
Input:
```
1
```
Output:
```
1
```
Explanation: Only one solution for 1x1 board.
