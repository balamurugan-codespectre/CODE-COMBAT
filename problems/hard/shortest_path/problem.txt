# Shortest Path in Unweighted Graph (Hard - 300 Points)

## Description
Given an unweighted undirected graph with `V` vertices (numbered `0` to `V-1`) and `E` edges, find the length of the shortest path (in terms of number of edges) between a given source vertex `S` and destination vertex `D`. If `D` is unreachable from `S`, print `-1`.

## Input Format
The first line contains `V` and `E`.
The next `E` lines each contain two integers `u` and `v` representing an undirected edge.
The last line contains `S` and `D`.

## Output Format
Print the minimum edge distance, or `-1`.

## Constraints
1 <= V <= 10^5
0 <= E <= 2*10^5
0 <= u, v, S, D < V

## Examples

### Example 1
Input:
```
5 5
0 1
0 2
1 3
2 3
3 4
0 4
```
Output:
```
3
```
Explanation: Path 0 -> 1 -> 3 -> 4 has 3 edges.
