Competition Rules & Guidelines

Welcome to CODE COMBAT. Please review the judging format and scoring mechanics.

1. Point Scoring Breakdown

Points are awarded exclusively when a submission passes 100% of the hidden test cases:

  • Easy Problem: 100 Points
  • Medium Problem: 200 Points
  • Hard Problem: 300 Points

Submitting multiple times after solving a problem will not duplicate points.

2. Offline Sandbox Execution

All programs are compiled and executed locally inside an isolated subprocess environment. Each test case enforces a strict time limit (default 2.0-3.0s). Infinite loops or excessive memory consumption will result in a TIME LIMIT EXCEEDED or RUNTIME ERROR verdict.

3. Tie-Breaking Criteria

Participants with identical total scores are ranked primarily by the total number of solved problems, followed by total execution runtime and earliest timestamp of the final accepted submission.
